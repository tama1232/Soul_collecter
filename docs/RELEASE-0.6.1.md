# 0.6.1 — 메인 개발자 계정과 쿠폰 권한

- 서버에서 owner로 확인한 메인 개발자 계정은 코드 등록·로그인·권한 동기화 시 현재 모든 캐릭터(56명, 8성 포함)를 보유하고 공개된 4장·28개 스토리를 선택할 수 있습니다. 기존 성장과 실제 클리어 기록은 유지합니다.
- 개발자 도구 → 플레이 테스트에 재화 종류/수량 입력을 추가했습니다. 영혼석·영혼 결정·별의 나침반·각성 파편·1~4장 정수의 보유 수량을 직접 설정합니다. 서버 권한을 확인하고 설정값을 장부에 남긴 뒤 현재 계정에 저장합니다. 처리 중 계정을 바꾸면 적용하지 않습니다.
- 부개발자 쿠폰 제작을 UI·Spark·Functions·Firestore 규칙에서 차단했습니다. 메인 개발자만 쿠폰을 발급합니다.
- 빠른 이동·돌진·넉백 시 도착 지점만 검사해 얇은 벽/바닥을 건너뛰던 충돌을 이동 경로 검사로 수정. 순간이동도 캐릭터 전체 크기로 벽 앞에서 멈추도록 처리.
- 미등록 개발자 코드와 사용/만료된 코드를 구분해 안내.
- Firebase 운영 규칙과 최초 코드 등록이 아직 적용되지 않은 프로젝트는 무료 설정 안내를 먼저 완료해야 합니다. GitHub Pages 배포가 Firebase 권한 배포를 대신하지 않습니다.

검증: 일반 테스트, 정적 모듈 검사·빌드. 별도 Firestore 에뮬레이터로 부개발자 직접 쿠폰 생성 차단과 메인 개발자 생성/일반 계정 조회를 확인했습니다. 실제 TileWorld에서 좌우 고속 이동, 낙하/천장, 순간이동, 일방향 발판/내려가기 회귀 검사를 포함합니다.

기존 Firebase 로그인 계정과 세이브는 삭제하지 않습니다.

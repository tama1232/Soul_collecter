# 0.4.0 검증 기록

`npm run check`, `npm test`, `npm run build`를 실행했습니다. 자동 테스트 29개가 통과했습니다.

- 기존 영웅 55명의 데이터 전체를 이전 개발본의 SHA-256 스냅샷과 비교했습니다. 기존 영웅은 동일하고, 8성은 타락한 신의 파편 한 명뿐입니다.
- 해금 전/후 일반·나침반의 확률 경계와 균등 구간을 확인했습니다. 10,000개 균등 입력에서 나침반 해금 후 6성 9,490 / 7성 500 / 8성 10건입니다. 이 검사는 사용자의 확률 경험을 보장하는 통계 추측이 아니라 구현한 구간 크기 검증입니다.
- 자연 8성이 7성 천장으로 덮이지 않으며, 잠긴 일반 계약과 임시 동료 제단에서 8성이 우회 획득되지 않습니다.
- 유물 10,000개 균등 입력의 등급 개수는 일반 4,500 / 희귀 3,000 / 에픽 2,000 / 전설 500입니다. 보유 중복과 같은 창 중복을 허용하고, 중첩 시 발동 객체와 문장 개수는 늘지 않습니다.
- 4권의 보스 순서가 3순환 이후에도 맞고, 동일 순서의 적보다 보상 배율이 더 빠르게 증가합니다. 실패·0처치·부분 보상과 중복 정산 방지를 확인했습니다.
- 실제 전투 엔진으로 히든 보스의 다섯 단계 패턴을 실행했습니다. 큰 피해도 네 번의 페이즈 전환을 건너뛰지 못하며 전환 중 무적이 적용됩니다. 해금·히든 방 체크포인트·일반 순서 복귀를 확인했습니다.
- 실제 플레이어 스킬 쿨타임과 표시 최대값에 순환당 0.5초가 더해집니다. 8성 근거리/원거리 액션 및 실제 상태이상 적용을 확인했습니다.
- 공용 체력·공격·스킬 301레벨 강화와 저장 정규화, 비용 상승 비율 증가를 확인했습니다. 강화 진행 바는 제거했습니다.
- 인연의 희귀도·돌파 배율, 미편성 수집 인연을 확인했습니다.
- 사자의 탑의 새 출정을 막고, 과거 탑 출정 저장을 정리합니다. 새로운 주차 점수도 정규화 후 유지됩니다.
- 한국 시간 일요일 경계, 세 부문 2개 지급, 동점자, 디버그 계정 제외, 서버 재시도와 클라이언트 중복 수령 방지를 테스트했습니다. 서버 검사는 가짜 Firestore 인터페이스를 이용한 단위 검사이며 실제 Firebase 운영 배포 검사는 아닙니다.
- 28개 스토리 데이터 생성, 각성 비용의 실제 차감, 출정별 독립 통계·정산 ID를 확인했습니다.
- DPR1/2/3 출력 배율, 60/120/144Hz 고정 업데이트, 포즈 상태 갱신, 전체 별도 PNG 아틀라스의 좌표·앵커·프레임 참조를 검사했습니다.
- 실제 메인 모듈과 계약·성장·강화·업적·칭호 스크롤·도감·편성·전투 화면 메서드를 실행했습니다. HD 스프라이트 18종의 실제 동적 모듈 import가 모두 resolve되는지도 확인했습니다. 남아 있던 preload 오류 처리의 미정의 함수를 제거했습니다.

마지막 화면 검사는 비활성 DOM/Canvas를 사용하는 Node 검사입니다. 브라우저 엔진이나 실제 픽셀을 재현하지 않습니다. 브라우저 도구의 접근 제한 때문에 실제 화면 레이아웃·색감·모바일 터치 검수는 완료하지 못했습니다.

다음 검수는 실제 기기에서 스토리 완전 플레이, 여러 순환 보스러쉬, 모든 영웅/유물 조합, 장기 비용·승률·프레임 시간, 본인 Firebase의 인증·규칙·다중 기기 충돌과 일요일 예약 실행입니다. 전체 그래픽·밸런스의 오류가 전혀 없다고 보증한 상용 검수 완료본은 아닙니다.

추가로 최초 개발자 코드의 전 계정 단일 소진, 보조 개발자의 코드 발급/초기화 거부, 전역 쿠폰 해시와 실제 쿠폰 처리의 일치, 서버 역할에 의한 주간 제외, 확률 개정 충돌·감사 장부, 계정 UID 바뀜과 권한 격리, 설정/파일 변조 보고를 확인했습니다. 무기 7성 픽업 50:50 경계, 유물 Lv5 포화와 등급 고갈 시 재정규화, 8성의 강화 수치와 실제 궁극기 회복/보호막 이벤트도 검사했습니다.

Firebase SDK를 설치하고 서버의 다섯 핸들러가 실제 import되는 것을 확인했습니다. Firebase 프로젝트를 생성하거나 실제 함수·보안 규칙을 배포했다는 의미는 아닙니다. 개발자 화면 여섯 탭은 같은 비활성 DOM 검사로 실행했습니다.

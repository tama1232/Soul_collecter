# 0.7.2 — 네메아의 잊힌 신성과 56명 이미지 교체

네메아가 7성의 스킬·돌파 설명을 재사용하던 구성을 금빛 마도서와 심연의 파편을 다루는 8성 고유 구성으로 바꿨습니다. 기존 캐릭터·무기 ID를 유지해 보유 여부, 레벨, 돌파, 정련과 8성 해금 기록을 이어갑니다. 다른 55명의 전투 데이터는 기존 스냅샷과 비교해 확인합니다.

| 항목 | 적용 내용 |
| --- | --- |
| 기본 능력치 | 요청한 수치로 공격력 **100**, 체력 **500** 고정. 8성의 강점은 스킬·패시브·무기에 반영 |
| 만상의 파편 · 5초 | 유도 파편 12개 × 600% = 기본 합계 7200%, 신성·심연 각 6개, 적 3회 추가 관통·지형 관통, 시전 중 무적 |
| 되찾은 성역 · 9초 | 800% 폭발, 체력 40% 회복·70% 보호막, 7초간 공격력 +80%·공격 속도 +50%·받는 피해 -20%, 6초간 따라오는 성역이 0.5초마다 300% 피해 |
| 잊힌 신의 귀환 · 24초 | 체력 100% 회복·100% 보호막, 화면 내 2000% 심판 3회 + 4000% 종언, 유도 파편 32개 × 800%, 시전 중 무적 |
| 잊힌 신의 기록 | 모든 피해 +60%·스킬 피해 +80%·보스 피해 +60%·받는 피해 -35%·흡혈 8%·스킬 쿨타임 -15%, 2.5초마다 240% 파편 3개, 모든 문장 및 직접 적중 시 5종 상태이상 순환 |
| 교대·공중·대시 공격 | 마도서 파편·신성 폭발 중심으로 교체. 교대는 2000% 폭발·20% 회복·40% 보호막 |
| 돌파 | 고유 스킬 피해·쿨타임, 최대 체력·모든 피해·보스 피해를 강화하도록 설명과 실제 효과를 함께 교체 |

표의 쿨타임과 피해 배율은 강화 전 기본값입니다. 패시브, 정련, 전용 효과, 스킬 강화, 돌파, 유물·문장·인연 등이 실제 수치에 반영됩니다. 파편 합계는 전탄 적중 시의 합산이며 관통에 따른 추가 대상 피해는 별도입니다.

전용 무기를 **망각의 서 「레퀴엠」**으로 변경했습니다. 기본 공격력 72는 기존 하위 등급 무기 최고치 24의 3배입니다. 0.6초 간격으로 유도 기록 3개(각 400%, 5정련 640%)를 발사하며 모든 피해 +40%·스킬 피해 +60%·보스 피해 +40%·받는 피해 -15%를 제공합니다. 스킬 사용 시 체력 15%만큼의 보호막과 두 일반 스킬의 쿨타임 0.5초 감소를 제공합니다(발동 간격 1초).

네메아 편성 전용 효과는 공격력 +40%·모든 피해 +30%이며, 네메아가 사용하는 두 일반 스킬 피해 +60%·궁극기 피해 +80%·궁극기 쿨타임 -6초가 적용됩니다. 무기 추가 공격은 `proc`으로 구분하고 발동 간격을 두어 스스로 무한히 추가 공격을 생성하지 않습니다.

53개 원본 PNG로 56명 전원의 448개 자세를 연결했습니다. 네메아는 소유자가 지정한 source 1-1이고, source7 추가 시트는 위에서부터 세레스·드라칸·아스테라·마리오네입니다. [이미지 대응 및 모션 안내](CHARACTER-ART.md)를 참고하세요.

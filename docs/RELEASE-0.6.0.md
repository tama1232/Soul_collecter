# 0.6.0 — 장 완료 성장 확장과 무료 운영 준비

- 캐릭터·스킬 최대 레벨 기본 10. 7개 스토리로 된 장 전체를 완료할 때 +10: 1/2/3/4장 완료 후 20/30/40/50. 개별 스토리·반복 클리어로는 늘어나지 않습니다.
- 성장 창의 상한/게이지/구매 제한을 공통 진행도로 연결. 상한이 늘어나면 접속 중 안내. 후반 장의 재화 수급 배율에 따라 10레벨 구간별 비용을 조정.
- 이전 버전에서 현재 진행도 상한을 넘긴 투자분은 한 번만 영혼 결정으로 환급. 환급된 능력이 남은 중단 플레이는 초기화하고 영구 진행도는 보존.
- Firebase Spark만 쓰는 개발자 REST 처리와 보안 규칙, 무료 GitHub 주간 집계/75% 용량 검사/암호화 보관 작업 추가. 유료 Cloud Functions 불필요.
- 자동화의 Google Cloud 인증은 운영 설정이 필요합니다. `docs/FREE-BACKEND.md` 참조. 워크플로 파일 추가만으로 활성화되었다고 간주하지 않습니다.

검증: 일반 테스트 47개, 모듈 검사, 정적 빌드. 별도 Firestore 에뮬레이터에서 최초/보조 개발자 원자적 등록, 중복 코드/권한 상승 차단, 비공개 세이브, 소유자 전용 초기화, 보상·칭호 위조 차단을 확인했습니다. 실제 운영 OIDC/예약 작업 성공은 아직 확인하지 못했습니다.

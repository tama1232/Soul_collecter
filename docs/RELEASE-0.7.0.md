# 잊힌 이름의 서 0.7.0

게임 이름을 이야기 속 사라진 이름과 기록서에 맞춰 「잊힌 이름의 서」로 변경했습니다. Firebase 프로젝트 ID, 로그인 이메일 도메인, 기존 저장 키는 계정을 보존하기 위해 유지합니다. GitHub 저장소 이름 변경은 GitHub 웹 인증 성공 후 별도로 적용해야 합니다.

## 성장과 전투

- 캐릭터·스킬·공용 체력/공격/스킬 강화: 시작 10, 스토리 한 권(7개 이야기) 완료마다 +10. 네 권 완료 시 50. 기존 초과 공용 강화는 현재 한도로 내리고 사용 재화를 한 번만 환급합니다.
- 보스러쉬 전투에서는 선택한 권에 따라 10/20/30/40으로 레벨·스킬·공용 강화를 보정합니다. 영구 저장한 투자 내역을 낮추지 않습니다.
- 각 권의 최대 성장, 각성 없는 중간 6성 조합, 강화한 6성 무기를 기준으로 보스 체력/공격을 다시 산정했습니다. 권 마지막 보스의 기준 유효 공격 시간은 79/86/93/100초입니다. 이동·회피·페이즈 전환으로 실제 시간은 길어집니다. 7성에는 추가 피해 15%, 체력 8%를 부여해 여유를 줍니다.
- 일반 적도 같은 성장 기준을 사용합니다. 첫 권 초반은 낮은 초기 능력치에서 시작하도록 완화하고, 무한 모드에는 층별 성장을 적용합니다.
- 2권 이후 페이즈 전환에 예고 후 발밑 공격, 3권에 재차 추적 공격, 4권에 안전 지대로 이동하는 ‘기억의 잔향’을 추가했습니다. 각 공격은 1.5초 동안 위치를 예고합니다. 기존 고유 패턴과 네 권/28개 이야기 수를 유지합니다.
- 모든 보스에 같은 체력바, 수치/백분율, 페이즈 경계, 다음 단계까지 필요한 피해를 표시합니다.
- 에녹·플로라에 궁극기를 추가했습니다. 네메아의 8/10/45초 재사용 대기시간 및 7성 원형 대비 1.5배 기본 능력치는 유지합니다.
- 보스러쉬 다음 권 보상은 기준 전투 시간 증가를 보정해 시간당 효율 1.5배를 목표로 조정했습니다. 재화/정수는 정수 반올림 차이가 있습니다. 보스러쉬와 무한 모드 보스에서 정수를 획득합니다. 보물방 골드는 감소했습니다.

## 조작과 화면

- `[프레임, 가로 속도, 세로 속도]` 이동 정보를 잘못 읽던 문제를 수정했습니다. 교대 시 전방 돌진을 제거하고, 대시·스킬의 중복 속도와 취소 시점, 이벤트 도중 동작 교체를 정리했습니다.
- 일반 근접 공격은 보이는 참격 범위에 맞추고 캐릭터 가까운 곳부터 판정합니다. 벽 너머 근접 공격을 차단합니다.
- 3~5성 및 네메아의 코드 기반 도트 실루엣에서 다리·상체 길이와 어깨 너비를 조정했습니다. 6~7성 전용 아트는 유지합니다.
- 긴 UI 문구를 가로로 압축하지 않고 생략합니다. 해당 문구에 마우스를 대거나 터치하면 큰 글씨의 전체 설명이 나옵니다. 도감 스킬/궁극기/교대/패시브도 같은 방식입니다.
- 업적 ‘모두 받기’를 터치/클릭할 수 있습니다. 첫 6성·7성, 공용 강화 20/40, 네 권 완주, 레벨 50 업적과 칭호를 추가했습니다. 이야기별 역대 시간 1위 칭호는 제거했습니다.
- 랭킹 이름은 ‘무한 N권’, ‘보스러쉬 N권’으로 표시합니다. 첫 화면 권 제목을 짧게 표시하고 설정/조작 아이콘을 개선했습니다.
- 같은 유물의 추가 획득으로 세트 효과 안내가 반복되지 않습니다.

## 계정과 운영 반영 상태

일반 저장 초기화는 서버에 등록한 개발자 권한을 지우지 않습니다. 메인 개발자는 초기화 직후에도 공개 영웅/장을 자동 해금합니다. 부개발자의 쿠폰 제작 차단도 유지합니다.

설정의 계정 영구 삭제 기능은 비밀번호 재인증과 확인 문구를 요구합니다. 본인 저장/랭킹/로그/주간 보상/칭호 보유 기록/개발자 권한을 정리한 후 Firebase Authentication 계정을 삭제합니다. 서버 정리 실패 시 인증 계정을 남겨 재시도합니다. 최소 삭제 표식은 다른 기기의 오래된 세이브가 복원되는 것을 막기 위해 유지합니다. 운영 Firestore 규칙을 새 버전으로 게시해야 이 기능을 사용할 수 있습니다. 테스트 과정에서 실제 Firebase 계정은 삭제하지 않았습니다.

매주 정산 및 75% 저장 용량 보관 작업의 코드는 준비되어 있지만, Google Cloud IAM/OIDC 연결과 GitHub 저장소 변수를 설정하기 전에는 자동 실행되지 않습니다. 유료 플랜으로 전환하지 않습니다. 자세한 내용은 [무료 백엔드 안내](FREE-BACKEND.md)를 확인하세요.

## 검증 범위

일반 테스트 60개, 모듈 연결/문법 검사, 빌드, 실제 Firestore 에뮬레이터 보안 검사. 실제 전투 엔진에서 전 영웅 56명의 공격·스킬·궁극기·대시·교대 동시 입력, 고속 벽 충돌, 페이즈 및 성장/보상 규칙을 확인했습니다. Canvas 렌더 결과로 도감·업적·도트 배치를 확인했습니다. 사람의 조작에 따른 승률이나 실제 시간당 보상은 플레이 데이터로 추가 확인해야 합니다.

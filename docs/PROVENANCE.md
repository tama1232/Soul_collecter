# 복원 출처와 범위

- 원본 서비스: https://xkv7.github.io/Contract/
- 공개 배포 저장소: https://github.com/XKV7/Contract
- 확인한 배포 버전: `mvks3w6m`, 2026-10-23.
- 원본 안내문은 이 저장소가 빌드된 플레이용 배포본만 포함한다고 명시합니다. 원본 개발용 소스, 커밋 전의 타입 정보, 주석, 미공개 서버 코드는 확보하지 않았습니다.

26개 활성 JavaScript 번들을 분석 대상으로 삼았습니다. 메인·데이터·성장·계약·도감·관리자 등 문자열 난독화를 해제하고, 엔진과 경제 규칙을 분리하고, 주요 클래스 및 데이터의 이름을 정리했습니다. 17개 별도 캐릭터 아틀라스와 메인에 포함된 PNG를 외부 이미지로 분리했습니다. 과거 버전 번들과 사용되지 않는 파일은 복사하지 않았습니다.

새로운 코드·문서와 원본 코드·이미지의 권리 범위는 다릅니다. 확인한 원본 파일 목록에는 LICENSE가 없었습니다. 이 프로젝트가 원본 저작권이나 원본 자산에 새로운 공개 라이선스를 부여하지는 않습니다. 원본 및 자산을 공개 배포할 권한은 프로젝트 소유자가 확인해야 합니다. 출처를 유지했고, 완성되지 않은 권리 정보를 임의로 채우지 않았습니다.

원본 Firebase 프로젝트의 설정과 저장소 키는 분리했습니다. 원본 관리자 인증을 우회하거나 원본 운영 데이터에 접속하는 코드는 추가하지 않았습니다. 원본의 저장 봉인·감사 기능은 유지하며, 개발자 도구 차단용 재귀 debugger와 F12 차단 로직만 제거했습니다.
